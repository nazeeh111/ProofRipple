# LAB v0.3

The workbench now starts with the experiment. A compact context and budget bar leads directly to the implication graph, proof inspector and candidate list. The previous marketing hero, repeated explanatory headings and large trust card have been removed from the primary reading path.

Charcoal surfaces, neutral borders and a single muted mint accent distinguish selected paths and verified states. Seed paths use a neutral solid line; selected or inspected consequences use a mint dashed line. Graph nodes and proof text retain their actual artifact data. The light theme's colors are not reused behind a dark overlay.

Formal basis, imported declaration audits, registered templates, benchmark qualifications, direct-automation control and the research trace remain available in native disclosure panels. The active axiom policy and each consequence's verification state stay visible. File-reported evidence and a fresh local verification remain explicitly distinct.

Existing controls retain their data contract: context, ranking policy, selected lemma budget and search budget. The three domains work independently; additional domains must provide real artifacts and explicit metadata rather than borrowing another domain's benchmark or trust assumptions. Every current benchmark denominator and negative result is retained.

The Mathlib set-lattice adapter uses a distinct context contract. It renders the retained proof AST directly, with set expressions and explicit AND joints for rules requiring both premises. These are proof steps, not invented unary implication edges or separately audited theorem declarations. A selected step shows its exact relation and role; the inspector retains the full candidate's formal audit and Lean source. Mathlib's pinned revision, imported `inf_sup_left` audit and allowed axioms appear in the formal-basis drawer. Its search budget is labeled as goal visits rather than BFS expansions. The Mathlib option becomes the default only when its real recorded artifact is available.

No remote fonts, decorative media, framework or client dependency was added. The graph remains generated from proof data. Keyboard tabs, visible focus, enlarged graph hit targets, mobile graph scrolling, JSON/Lean export and error retention are preserved. Desktop and mobile previews must be generated from this source into new v0.3 output folders; v0.2 release media is preserved.
